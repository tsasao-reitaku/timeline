# ポケベル インタラクティブ年表

ポケベルの加入数推移と、関連する社会的出来事（制度・技術・文化・競合サービス）を
同じ時間軸で確認できるインタラクティブ年表です。

## 使い方

- 左側の行名をクリックすると、その行に属する出来事が一覧表示されます。
- グラフ上の点をクリックすると吹き出しが固定表示されます（再クリックで解除）。
- 吹き出しはドラッグで移動できます。
- 上部のメニューから、実数／指数（1988年=100）の表示切替ができます。
- 「転換点を追加」から、任意の年に注釈線を追加できます。
- SVG・PNG・PDF（印刷ダイアログ経由）として書き出せます。

## データの読み込み

出来事CSV・定量CSVのひな型はこのリポジトリに同梱しています。
CSVはブラウザ内で処理され、外部サーバーへ送信されません。

- `出来事CSVひな型.csv`：年,大分類,小分類,出来事,説明,出典,URL
- `定量CSVひな型.csv`：年,値,系列名（全行同じ名前）
