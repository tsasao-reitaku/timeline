# 定量×出来事 インタラクティブ年表

このリポジトリは、**自分の定量データ（数の推移）と出来事のデータを読み込ませるだけで、
定量グラフと出来事年表がインタラクティブに連動した可視化を作れるツール**です。

今表示されている「ポケベルの普及・衰退と社会的出来事」は、使い方を理解してもらうための
**サンプル（お手本）**です。仕組みそのものはポケベル専用ではなく、CSVファイルの中身を
入れ替えるだけで、どんなテーマの年表にも作り替えられます。

## まずはサンプルを触ってみる

- 出来事は行（大分類｜小分類）ごとに、タイトルが常時1行で表示されます。年代が近い
  出来事は自動的に段を分けて重ならないようにしています。
- 出来事をクリックすると、詳細説明・引用文・出典を含めた全文が吹き出しで開きます。
  もう一度クリックすると閉じます。
- 行名をクリックすると、ページ下部のパネルにその行の出来事が一覧表示されます。
- グラフ右上のパネルから、以下の操作ができます。
  - 「年表を書き出し」：SVG・PNG・PDFとして書き出し
  - 「新規年表を作成」：別のCSVファイルを選んで読み込み直す（後述の「自分の年表を作る」はこちら）
  - 「転換点」：グラフ上をクリックして注釈線を追加／タグの「×」で削除
  - パネル右上の「－」／「＋」で、パネル自体の表示・非表示を切り替え
- グラフ上にマウスを乗せると、縦の点線と該当年の値が表示されます。

## 自分の年表を作る

サンプルの仕組みを理解したら、自分が調べたいテーマ（技術・文化・社会現象など何でも
構いません）で、以下の2つのCSVファイルを自分で作ってみましょう。

- **出来事CSV**：年ごとの出来事を1行ずつ入力する表
  列：`年（必須）,大分類（必須）,小分類,出来事タイトル（必須）,詳細説明,引用文,出典,URL`
- **定量CSV**：年ごとの数値の推移を入力する表（人口・売上・件数など何でも構いません）
  列：`年（必須）,値,系列名（全行同じ名前）（必須）`

作り方の目安：

1. 画面右上の「新規年表を作成」から、それぞれの「ひな型をダウンロード」でCSVの
   見本を入手する（現在表示中のデータがそのままCSVとして書き出されます）
2. Excel・スプレッドシートなどで、自分のテーマの内容に書き換える
3. 同じ画面から、書き換えたCSVを選んで読み込む → その場でグラフと年表に反映される
4. 気に入った内容になったら、画面右上の「年表を書き出し」からSVG・PNG・PDFの
   いずれかで保存する

読み込みはこのブラウザの中だけで完結しており、サイト本体やGitHub上のファイルが
書き換わることはありません。作った年表を人に見せたり提出したりしたい場合は、
上記の書き出しファイルを使ってください。
